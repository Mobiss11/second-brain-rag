# Правила для агента, который работает с этим репозиторием

Репозиторий - каркас второго мозга. База знаний в `knowledge/`, поиск и ответ в `rag/`.
Задача агента: развернуть, прогнать, адаптировать под проект владельца.

## Порядок действий

1. Прочитать `README.md` и `docs/ARCHITECTURE.md`.
2. Выполнить `pip install -r requirements.txt` (или venv, как в README).
3. Запустить `python -m rag.ingest --dry-run` и показать владельцу, как режется база.
4. Заменить `knowledge/example.md` материалами проекта. Не больше одного факта
   на блок, блоки через `---`.
5. Подставить ключи в `.env` (не в код), собрать `python -m rag.ingest`.
6. Прогнать 10-20 реальных вопросов, показать ответы и источники.
7. Подобрать `MIN_SCORE` на этих вопросах.

## Что нельзя

- Класть ключи и токены в код или в базу знаний.
- Заполнять базу персональными данными без обезличивания.
- Оставлять в промпте `rag/query.py` правило, разрешающее отвечать без контекста.
- Говорить владельцу, что всё работает, пока не прогнаны реальные вопросы.

## Как менять роли и тон

Роль и правила ответа - `SYSTEM` в `rag/query.py`. Менять только их, остальную
логику не трогать. После правки прогнать вопросы заново.

## Проверка

```bash
python -m pytest tests -q
python -m rag.ingest --dry-run
```
